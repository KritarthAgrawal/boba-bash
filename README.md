## ✨ About the Project

**The Evolution of Earth** is a cinematic storytelling website that presents Earth's history through a sequence of immersive, full-screen sections.

Instead of presenting history as a conventional article, the website uses scrolling as a storytelling mechanism. Each section introduces a new era, accompanied by atmospheric background photography, elegant typography, and smooth visual transitions.

The experience combines science, design, and frontend development to make Earth's extraordinary journey engaging and accessible.

## 🚀 Key Features

- 🌌 **Cinematic Scrolling:** Explore Earth's history through immersive, full-screen sections.
- 🖼️ **Dynamic Backgrounds:** Smoothly crossfade between photographs as the story progresses.
- ✨ **Scroll-Triggered Animations:** Reveal headings, paragraphs, and facts as they enter the viewport.
- 📊 **Reading Progress Bar:** Track progress through the entire experience.
- 🎨 **Minimal Visual Design:** Dark backgrounds, warm golden accents, and elegant typography.
- 📱 **Responsive Layout:** Flexible typography and spacing for different screen sizes.
- ♿ **Reduced-Motion Support:** Respect system preferences for reduced animation.
- 📖 **Narrative Storytelling:** Present scientific milestones in an engaging, chronological journey.

## 🎬 Design & Animation

### 1. Background Crossfading
A fixed photographic backdrop creates a continuous visual environment. Background images fade between historical sections rather than cutting abruptly.

### 2. Progressive Text Reveals
Headings and paragraphs appear in sequence with subtle opacity and vertical-position transitions.

### 3. Scroll Progress Indicator
A thin golden line at the top of the screen updates as visitors move through the website.

### 4. Cinematic Typography
Fraunces provides expressive editorial headings, while Instrument Sans keeps the main content clean and readable.

### 5. Atmospheric Visuals
Dark overlays, slow image scaling, and warm golden highlights help create an immersive experience.

## 💻 Getting Started

Run the project locally using the following steps.

### Prerequisites

- A modern web browser
- Visual Studio Code or another code editor
- Git (optional, for cloning the repository)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/kritarthagrawal/boba-bash.git
```

**2. Open the project directory**

```bash
cd boba-bash
```

**3. Run the website**

Open `index.html` directly in your browser or launch it using the Live Server extension in Visual Studio Code.
